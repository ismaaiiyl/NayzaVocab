# Role: Senior Flutter & UX Architect
# Task: Refactor NayzaVocab to support "Vocab Sets" with Bulk Input and Enhanced History.

The goal is to transition from individual word storage to a "Collection-based" system (like Quizlet or Anki).

## 1. Data Structure Update (Models)
- **VocabSetModel**: 
  - `id` (String), `title` (String - e.g., "Family", "Work"), `createdAt` (DateTime).
  - `List<WordModel> words`: A nested list of words belonging to this set.
- **WordModel**: 
  - `original`, `translation`, `langCode`, `isLearned`, `wrongAttempts`.

## 2. Bulk Input UI (The "Environment Variable" Style)
- Create a `CreateSetScreen`.
- **Top Part**: An `InputTextField` for the "Set Title".
- **Dynamic List**: Use `ListView.builder` with a dynamic list of controllers.
  - Each row contains: `Word Input`, `Translation Input`, `Language Selector`, and a `Delete Icon`.
- **Add Row Button**: A "+" button at the bottom to inject a new empty row (Word/Translation pair) dynamically.
- **Save Logic**: Validate that all inputs are filled, then wrap them into a `VocabSetModel` and save to Hive.

## 3. History & Navigation Refactor
- **HistoryScreen**: Instead of a flat list, display "Collection Cards".
  - Card shows: `Title`, `Date`, `Word Count` (e.g., "15 words").
  - On Tap: Navigate to `SetDetailsScreen`.
- **SetDetailsScreen**:
  - Display all word pairs in the set.
  - **Edit Mode**: Add a "Pen/Edit" icon on each row and the Title. 
  - Ability to add more words to an existing set.
  - **Stats**: Show "Missed/Learned" ratio for this specific set.

## 4. Multi-Language TTS Engine
- Support: `en-US` (English), `ru-RU` (Russian), `ar-SA` (Arabic), `de-DE` (German).
- **Logic**: Only trigger `flutter_tts` for the `original` word. Skip audio for Uzbek translations.
- **RTL Support**: If `langCode == 'ar-SA'`, the word input/display must use `TextDirection.rtl`.

## 5. UI/UX Refinements
- **Icons**: Use `LucideIcons` or `FontAwesome` for a modern look.
- **Transitions**: Use a "Hero" animation when transitioning from the History Card to the Set Details.
- **Buttons**: Use the defined "Electric Gold" (#FFD700) for "Add Variable" and "Save" buttons to match the Nayza brand.

Please provide the implementation for `vocab_set_model.dart`, the dynamic `CreateSetScreen` logic, and the grouped `HistoryScreen`.
