**Nayza Vocab** — Ingliz tili va boshqa xorijiy tillarni o'rganuvchilar uchun mo'ljallangan, zamonaviy va intuitiv lug'at boshqarish ilovasi. Nayzadoridek tez va oson so'zlarni yodlang! 🔱🚀

## ✨ Imkoniyatlar (Features)

- **💎 Premium Design**: Glassmorphism va Material 3 asosidagi zamonaviy interfeys.
- **🔊 Audio/TTS Support**: So'zlarning to'g'ri talaffuzini tinglash imkoniyati (Ingliz, Arab, Rus tillari).
- **🎓 Smart Quizzes**: Unikal variantlar va mantiqiy distraktorlar bilan boyitilgan test tizimi.
- **📂 Selective Backup**: To'plamlarni tanlab JSON formatiga eksport va import qilish.
- **🛠 Offline First**: Barcha ma'lumotlar qurilmangizning o'zida (Hive) xavfsiz saqlanadi.
- **📳 Tactile Feedback**: Haptik aloqa (vibratsiya) orqali boyitilgan foydalanuvchi tajribasi.

## 🛠 Texnologiyalar (Tech Stack)

- **UI Framework**: Flutter (Material 3)
- **State Management**: Provider
- **Local Database**: Hive (NoSQL)
- **Audio**: Audioplayers & Flutter TTS
- **Animations**: Lucide Icons & Custom Micro-animations

## 🚀 O'rnatish (Getting Started)

1.  Ushbu repo'ni klonlang:
    ```bash
    git clone https://github.com/tolibi_cyber/nayza-vocab.git
    ```
2.  Bog'liqliklarni yuklab oling:
    ```bash
    flutter pub get
    ```
3.  Ilovani yurgizing:
    ```bash
    flutter run
    ```

## 🔐 Xavfsizlik (Security)

Loyihada **Signing Keystore** sozlamalari mavjud. O'zingizning shaxsiy APK faylingizni build qilish uchun `android/key.properties` faylini yaratishingiz shart. (Misol uchun `android/key.properties.example` ga qarang).
